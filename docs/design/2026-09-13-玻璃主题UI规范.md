# Tripfolio 玻璃主题 UI 规范 v1.0

日期：2026-09-13  
适用：玻璃主题下的桌面网页、移动网页与 Capacitor 安卓界面。  
交付状态：材质与组件规范、交互效果示例；本文件定义目标效果，不表示现有业务界面已经完成接入。

## 1. 材质定义

采用**浅色透光玻璃**：背景的绿、米色能透进面板，细节经过轻度磨砂而柔化；边缘存在明暗变化与可感知的厚度，面板通过投影悬浮于背景之上。文字、图标和操作始终清晰。

必须同时体现以下五层，缺少任何一层都不能作为最终玻璃效果交付：

| 层次 | 视觉要求 | 实现原则 |
| --- | --- | --- |
| 背景透色 | 同一面板的不同位置能呈现背景带来的细微色差 | 背景有低频色块，表面使用带 alpha 的填充 |
| 轻度磨砂 | 背景大轮廓保留，细字与网格柔化 | 只模糊面板后方，内容本身不模糊 |
| 表面反光 | 左上有轻薄反光，中心保持通透 | 宽而弱的渐变，避免大面积白色覆盖 |
| 边缘厚度 | 外亮、内柔、下缘略暗，转角延续光线 | 1px 外缘、1px 内高光与下缘暗线配合 |
| 空间投影 | 能看出面板与背景之间存在距离 | 接触阴影与扩散阴影分开控制 |

视觉优先级：**文字可读性 > 玻璃边缘 > 背景透色 > 空间投影 > 磨砂强度**。玻璃感不足时，先检查边缘和透色，不先增加模糊。

## 2. 光源与背景

- 全站固定为左上方柔光。上边和左上转角最亮，右侧较弱，下边保留一条很轻的暗线与局部反光。
- 页面底色沿用 `#e6ece6`；背景光斑使用叶绿 `#83b89b`、浅绿 `#cfe3c4`、暖米色 `#dfbb8b`。沿用全站禁止蓝紫色的既有约定。
- 同屏使用 2–3 个大色块，直径约为视口短边的 40%–70%；至少一个色块经过主要玻璃面板后方，不能全部堆在页面四角。
- 色块边界足够柔和，但保留可观察的色差。背景纹理可选，网格不透明度不超过 3%，间距至少 64px。
- 列表、地图、照片已经提供足够背景变化时，不再增加光斑。密集照片与表格后方优先提高阅读区填充，而不是让正文与背景细节互相干扰。
- 背景不持续漂移，面板不跟随指针倾斜，反光不循环扫动。

## 3. 表面分级与默认参数

表中的 alpha 是白色底层的**不透明度**，不是元素 `opacity`；“允许区间”用于不同背景下的校准，默认值为设计基准。文字不跟随表面透明度变化。

| 组件层级 | 白色底层 alpha | 背景模糊 | 饱和度 | 圆角 | 深度 |
| --- | --- | --- | --- | --- | --- |
| 导航栏、工具栏 | 0.36（0.30–0.42） | 8px | 115% | 沿用壳层形状 | 一级 |
| 卡片、普通面板 | 0.40（0.34–0.46） | 10px | 115% | 20px | 二级 |
| 对话框、抽屉 | 0.46（0.40–0.54） | 12px | 115% | 24px | 三级 |
| 菜单、日期选择浮层 | 0.60（0.56–0.68） | 10px | 110% | 12px | 二级 |
| 输入框、文本域 | 0.54（0.48–0.64） | 不新增模糊 | 不新增饱和度 | 12px | 轻内凹 |

约束：

1. 普通面板与弹窗默认模糊不超过 12px。极复杂背景可以到 16px，超过前先调整背景或阅读区填充。移动端的普通面板与弹窗以 8px 为起点。
2. 面板反光渐变的白色 alpha 峰值为 0.14，中心为 0；不得再次叠加高不透明度的整面白色渐变。
3. 弹窗默认底层 0.46 与反光峰值 0.14 合成后为 `1 - (1 - 0.46) × (1 - 0.14) ≈ 0.536`，仍能透色。即使校准至底层 0.54，反光区域也应低于 0.61；1–2px 的明亮边缘不受此上限约束。
4. 输入框等小型阅读区允许更实，以保证可读性；弹窗内部不再嵌套完整玻璃卡片。嵌套区域优先使用间距、分隔线和轻填充。
5. 菜单等浮层独立承载文字，可提高底色，但仍保留边缘高光。长表格和文字密集区可使用不透明阅读底，不强制所有内容都透明。

## 4. 弹窗的高亮边缘与厚度

弹窗是玻璃主题中材质表达最明显的组件。静止时就必须看见高亮边缘，不能依赖鼠标悬停。

| 部位 | 默认规格 | 作用 |
| --- | --- | --- |
| 外侧亮边 | 1px；顶部与左上白色 alpha 0.96–0.98，侧面约 0.45–0.65 | 形成玻璃切面的亮线 |
| 内侧高光 | 向内 1px 的上缘高光，白色 alpha 0.82 | 让边缘呈现厚度 |
| 次级内反光 | 内缘约 2px 范围，白色 alpha 0.10–0.16 | 避免边缘只像描了一条白线 |
| 下缘暗线 | 1px；深绿黑 alpha 0.08–0.12 | 区分厚度与投影 |
| 上方宽反光 | 白色 alpha 从 0.14 逐渐降至 0，约到面板 40% 处消失 | 表现表面受光 |
| 外部光晕 | 默认关闭 | 亮度集中在边缘，避免霓虹感 |

四边亮度不得完全相同；高光沿圆角连续过渡，不使用矩形边线破坏转角。局部亮边可以接近纯白，但宽度不超过 2px。

三级投影基准：

```css
/* 低处的小阴影表达接触，远处的大阴影表达悬浮高度。 */
--tf-shadow-1: 0 2px 4px rgb(20 44 32 / 0.06);
--tf-shadow-2:
  0 3px 6px rgb(20 44 32 / 0.05),
  0 16px 32px -14px rgb(20 44 32 / 0.18);
--tf-shadow-3:
  0 2px 4px rgb(20 44 32 / 0.08),
  0 16px 40px -12px rgb(20 44 32 / 0.20),
  0 36px 80px -24px rgb(20 44 32 / 0.22);
```

普通卡片的亮边和投影弱于弹窗，避免整个页面每个块都争夺注意力。

## 5. 遮罩与弹窗布局

- 遮罩默认 `rgb(20 36 28 / 0.16)`，允许 0.12–0.20。较复杂业务场景可以到 0.24，不能靠重灰遮罩制造玻璃感。
- 遮罩只压低背景亮度，默认不做全屏模糊；磨砂由弹窗自身承担，避免全屏模糊与弹窗模糊叠加。
- 遮罩使用带 alpha 的背景色，不通过降低整个弹窗祖先的 `opacity` 实现。
- 背景点击区和玻璃弹窗为同一层级的独立元素；避免带 `filter`、永久 `opacity < 1` 的祖先把弹窗与真实背景隔开。保持既有 Dialog/Popup 的传送、滚动锁定、焦点管理和关闭语义。
- 桌面标准表单宽度 640px，可到 680px；左右安全距离至少 24px。上下安全距离至少 24px，整体最大高度 `calc(100dvh - 48px)`。
- 长表单只在正文区滚动，标题、关闭按钮和操作区保持可达。不要为了裁切材质伪元素而裁切焦点环、日期浮层或下拉菜单。
- 桌面内边距 28px，移动端 20px；移动弹层与屏幕两侧至少相隔 16px。底部抽屉保留安全区间距。
- 标题和页脚都属于同一玻璃面板，不再各自叠加白色卡片或额外模糊层。

## 6. 文字、控件与状态

### 文字与间距

- 沿用项目系统中文字体栈。页面标题 28px/600，弹窗标题 20px/600，正文与字段标签 14px/400，说明文字 12–13px/400；移动端输入文字至少 16px。
- 主文字 `#1c201e`，正文 `#39483f`，辅助文字 `#435347`。辅助文字也以 4.5:1 为目标，不能通过降低整个文字节点透明度来弱化。
- 正文行高 1.5–1.6。字段标签与控件间距 8px，字段组间距 20px，语义分区间距 28px，按钮间距 12px。
- 桌面表单控件高度 40px，主要触控目标至少 44px。密度需要降低时增加留白，不把控件缩到难以点击。
- 控件圆角 12px，卡片 20px，弹窗 24px。紧密嵌套时遵守“外圆角 = 内圆角 + 间距”；相隔超过 24px 的独立表面按各自层级取值。

### 控件

| 组件 | 规范 |
| --- | --- |
| 输入框 | 半透明白底，1px 结构边线，顶部轻内阴影；不单独使用 `backdrop-filter` |
| 主按钮 | 沿用青绿 `#1f7a6d` 与白色文字，配轻微顶缘高光和一级阴影，保持清晰的主操作层级 |
| 次按钮 | 浅透明填充、可见轮廓和深色文字，亮度弱于主按钮 |
| 危险操作 | 使用文字、图标与危险色共同表达；确认弹窗保留相同玻璃材质，不把整块玻璃染红 |
| 标签 | 低饱和浅填充；文字保证对比度，不做独立模糊与重投影 |
| 关闭按钮 | 图标清晰，触控区域 44px；位于高光内侧，不压住玻璃边缘 |
| 列表、表格 | 一个外层玻璃容器；内部行使用分隔线和轻度选中填充，避免每行成为一块玻璃 |
| 空状态、加载 | 放在现有面板内部；骨架使用稳定浅填充，加载不能擦除已填写的表单内容 |

### 状态与动效

- Hover：控件填充 alpha 提升 0.04–0.06，或边线加深；可交互卡片最多上移 1px。非交互面板没有 hover 浮动。
- Focus：使用稳定的青绿色可见焦点环，不与白色材质高光混淆；与邻接颜色达到至少 3:1。字段边线不能只靠白色高光指示。
- Press：按钮 `scale(0.96)`，时长 120ms；可通过静态状态关闭缩放，表单输入不缩放。
- Disabled：仅降低填充和边线强调度，保留可识别文字；不对整个组件设置低 `opacity`。示例禁用文字可取 `#637267`。
- Error：边线、图标与说明共同呈现，错误说明保持 4.5:1；不能仅把透明底染红。
- Loading：按钮保留宽度，使用忙碌文案与 `aria-busy`，阻止重复提交。
- 控件反馈 120ms；面板入场 220ms、从下方 6px 回到原位；退出更轻，使用 120ms 和最多 4px 位移。入退场用 `ease-out`，普通状态沿用 `cubic-bezier(0.2, 0, 0, 1)`。
- 不动画模糊半径，不使用 `transition: all`；不常驻 `will-change`。主题切换沿用现有一帧禁用过渡机制。
- `prefers-reduced-motion: reduce` 下关闭位移、缩放和过渡，所有状态仍由颜色、文字或图标表达。

## 7. 可落地的弹窗材质配方

下面是材质参考；接入时放入玻璃主题装饰层，对现有表面选择器应用，不复制到页面私有样式。不负责 Dialog 的焦点、层级与关闭逻辑。`--glass-*` 是装饰层的私有参数，不加入页面依赖。

```css
[data-theme='glass'] .glass-dialog-surface {
  --glass-alpha: 0.46;
  --glass-blur: 12px;
  position: relative;
  border: 1px solid rgb(255 255 255 / 0.44);
  border-radius: var(--tf-radius-panel);
  background-color: rgb(255 255 255 / var(--glass-alpha));
  background-image: linear-gradient(
    135deg,
    rgb(255 255 255 / 0.14),
    rgb(255 255 255 / 0) 40%,
    rgb(255 255 255 / 0.04)
  );
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(115%);
  backdrop-filter: blur(var(--glass-blur)) saturate(115%);
  box-shadow:
    var(--tf-shadow-3),
    inset 0 1px 0 rgb(255 255 255 / 0.82),
    inset 1px 0 0 rgb(255 255 255 / 0.40),
    inset 0 0 0 2px rgb(255 255 255 / 0.12),
    inset 0 -1px 0 rgb(20 44 32 / 0.10);
}

/* 薄亮切边，不覆盖或模糊正文。组件已有伪元素时改用装饰子元素。 */
[data-theme='glass'] .glass-dialog-surface::before {
  content: '';
  position: absolute;
  inset: 0;
  z-index: 2;
  padding: 1px;
  border-radius: inherit;
  pointer-events: none;
  background: linear-gradient(
    135deg,
    rgb(255 255 255 / 0.98),
    rgb(255 255 255 / 0.62) 32%,
    rgb(255 255 255 / 0.20) 62%,
    rgb(255 255 255 / 0.60)
  );
  -webkit-mask:
    linear-gradient(#ffffff 0 0) content-box,
    linear-gradient(#ffffff 0 0);
  mask:
    linear-gradient(#ffffff 0 0) content-box,
    linear-gradient(#ffffff 0 0);
  -webkit-mask-composite: xor;
  mask-composite: exclude;
}

@media (prefers-reduced-transparency: reduce) {
  [data-theme='glass'] .glass-dialog-surface {
    background: #edf2ed;
    -webkit-backdrop-filter: none;
    backdrop-filter: none;
  }
}

@supports not (
  (backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))
) {
  [data-theme='glass'] .glass-dialog-surface {
    background: #edf2ed;
  }
}
```

这是 CSS 对玻璃材质的近似表达，不依靠真实光线追踪或文字形变。高光伪元素不得拦截输入；禁止对包含文字的面板使用 `filter: blur()`。如果需要局部反光，仍须限制在装饰层。

## 8. 与现有主题体系的映射

继续遵守 `tokens.css → decor.css → 组件库桥接 → 页面语义令牌` 的分层，不让页面直接依赖 Element Plus 或 Vant 的主题变量。

| 现有入口 | 接入目标 |
| --- | --- |
| `apps/client/src/themes/glass/tokens.css` | `surface=0.40`、`surface-raised=0.46`、`surface-sunken=0.54`、`surface-blur=10px`、轻遮罩及三级阴影；保留完整令牌集合 |
| `apps/client/src/themes/glass/decor.css` | 分开普通表面与弹窗的反光、模糊和高光强度；删除弹窗 0.8 白底与 0.6 峰值白色渐变的旧组合 |
| `apps/client/src/styles/bridge/element-plus.css` | 背景继续映射语义令牌；检查 Dialog、Drawer、MessageBox 和独立下拉浮层实际渲染效果 |
| `apps/client/src/styles/bridge/vant.css` | 同一材质方向，移动端减小模糊；检查 Popup、NavBar、CellGroup 与底部安全区 |
| `apps/client/src/shared/theme/tokens.ts` | 公共令牌保持封闭契约；若增加公共令牌，所有主题和令牌测试必须同步更新 |

装饰只能使用已批准的表面钩子和组件库表面选择器。上面的 `.glass-dialog-surface` 是配方占位名，实际接入优先复用 `.el-dialog`、`.el-message-box`、`.el-drawer`、`.van-popup`，不要求页面新增私有装饰类。独立菜单/日期浮层若尚未列入表面清单，接入时同时更新清单与桥接规则，不能依靠页面选择器绕过契约。

现有实现的关键问题：弹窗底色 0.80 叠加白色反光 0.15–0.60，等效白色不透明度约 0.83–0.92；减少透明遮罩或单纯增大模糊都不能消除这层白板感。

## 9. 降级与验收

### 降级

- 不支持 `backdrop-filter`、系统要求减少透明度或性能不足时，使用实色 `#edf2ed`；保留高光和可辨认边线，关闭模糊。
- 降级底色必须真正不透明，不能继续引用 alpha 为 0.46 的 `surface-raised`。系统媒体查询并非所有平台都支持，目标 WebView 仍需实机检查。
- 不在整页、每个字段、每一行同时使用模糊。尽量只保留一个主要模态表面，打开菜单时检查叠层合成与滚动性能。

### 验收清单

- [ ] 同一玻璃面板移到绿色与暖米色背景上时，能看见相应透色变化。
- [ ] 默认状态下仍能识别背景大色块；背景细字柔化，正文、数字、图标保持锐利。
- [ ] 100% 缩放时，弹窗顶部及左上转角有清晰连续的亮边；下缘存在细微厚度线。
- [ ] 四边高光有强弱差异，没有粗白框、大光晕或中央大片白斑。
- [ ] 弹窗相对卡片有更明显的空间高度，普通卡片不使用同等级重阴影。
- [ ] 打开弹窗后背景保留色彩，整页不会变成明显灰幕；点击、焦点、滚动锁定和关闭行为正常。
- [ ] 正文、字段标签、提示与按钮文字在**实际合成背景**上达到 4.5:1；大字与必要非文字指示至少 3:1。分别检查绿色、米色、亮色和复杂背景。
- [ ] 键盘焦点、hover、press、disabled、error、loading、empty 均清晰可辨，不依赖动画。
- [ ] 在 1366×768 与 390×844 检查长表单，操作区可达、无横向溢出；320px 窄屏不挤压必要操作。
- [ ] Chrome/Chromium 实际截图与移动 WebView 实机检查通过；CSS 参数正确不能代替材质视觉验收。
- [ ] 减少动态、减少透明度、不支持模糊时均可正常阅读和操作。

本次示例只用于材质与交互方向核验；应用组件集成、业务回归和安卓实机结果应在后续接入时单独记录。

## 10. 本次示例核验记录

- 在 Chromium 中查看了 736px 与 390px 宽度的实际渲染；320px 宽度下检查控件边界，无横向溢出。桌面实际计算值为 `blur(12px) saturate(1.15)`，窄屏为 `blur(8px) saturate(1.15)`。
- 已观察到绿色、暖米色透色，以及顶部与圆角处的连续亮边；背景细节柔化，表单文字保持清晰。
