# 高德地图与行程路线

日期：2026-09-14。对应用户追加需求与网页版进度 5.G，优先于相册/预订模块。

## 交付范围

- 每日行程的新建/编辑支持搜索高德兴趣点和地图点击选点，确认后自动保存标题、地点名、地址与 GCJ-02 经纬度；2026-09-15 起移除独立标题、地点、地址输入框，旧记录可继续编辑其他字段。
- 相邻行程点自动计算驾车、步行或骑行的道路距离与预计时长；新增、删除、改地点、拖动排序后重新计算受影响的路段。
- 行程页可通过球形地图图标切换地图视图；2026-09-15 起移除账单页地图入口。地图默认展示整趟旅行的所有有坐标点位，按日期、sort_order、id 的顺序编号并绘制路线，可筛选单日。
- 只估算交通路段，不把停留时间计入交通时长；不擅自优化或改变用户排列的顺序。跨日接续路段单独标注。
- 无坐标项目保留在列表并计数提示；没有道路路线或服务不可用时，显示“示意连线”，不把直线长度伪装成道路距离，汇总标明仅包含成功计算的路段。

## 后端与接口

- `modules/geo` 定义供应商无关的地点、坐标、路线和输入校验，`adapters/geo` 实现高德 Web 服务调用。HTTP 只负责认证、参数转换与响应；bootstrap 显式装配。
- `GET /geo/reverse-geocode`：latitude、longitude，返回 `{data: GeoPlace}`。
- `GET /geo/places`：q、city?、latitude?、longitude?（必须成对），返回 `{data: GeoPlace[]}`，最多 20 个可选 POI；无结果为 404。
- `GET /geo/routes`：origin_latitude、origin_longitude、destination_latitude、destination_longitude、mode（driving/walking/cycling），返回 `{data: GeoRoute}`；包含道路距离米数、预计秒数和 GCJ-02 路线点数组。
- 非法/非有限坐标、半个坐标对、非法出行模式在请求上游前拒绝为 422。认证缺失 401，账号限流 429 + Retry-After，无地点/路线 404，配额不足或上游失败 503。
- 逆地理编码仍用约 100 米网格缓存地址，但返回的坐标始终为本次选点坐标，避免缓存命中后位置漂移。路线按 6 位小数的有序起终点和出行方式缓存 5 分钟，缓存容量有上限。
- Web 服务 Key 仅存在于 Go 环境变量；上游网络错误不记录包含 Key 的 URL。搜索/算路均走带账号身份的自有 API。

## 前端与安全代理

- JS API 2.0 按需加载，失败可重试；地图实例在卸载时销毁，隐藏状态不提前初始化。
- JS API Key 通过 `VITE_AMAP_JS_KEY` 配置（公开浏览器标识）；安全密钥 `AMAP_JSCODE` 只由 Vite 开发代理或 Caddy 追加，禁止 VITE 前缀和前端明文注入。
- `VITE_AMAP_SERVICE_HOST` 可配置绝对代理地址；默认同源 `/_AMapService`。Capacitor 部署应提供可访问的 HTTPS 代理地址。
- 搜索结果与标记均以文本渲染，地图点位列表支持键盘操作；保留地图版权信息。加载、空结果、未配置、错误和部分路段失败都有可恢复提示。
- 地点选择同时更新标题/地点/地址/经纬度；清空选点时清空位置快照，避免旧文字与新坐标错配。新建项目须选点，旧记录不强制补定位；不因无关编辑丢失旧标题和历史预计费用。
- 逆地理编码尚未完成时暂停保存，避免保存旧选点；失败仍保留本次点击坐标并提示地址未查到。坐标输入回车仅确认选点，不误提交行程。
- 算路有取消、按供应商 Key 的请求节奏控制与成功结果短期缓存；短时限流／暂时不可用进行有限、可取消的退避重试，配额耗尽／凭证错误／无路线不盲重试。单段暂时失败不能跳过后续路段；切换模式/日期或离开页面时旧响应不能覆盖新视图。距离/时长按成功路段汇总，失败时不显示完整总里程。
- 地图区域内滚轮用于缩放且不带动页面滚动，缩放以鼠标指针位置为锚点（指针下的地点保持不动，指针位于中心时等同于按中心缩放）；移除地图放大／缩小按钮，保留键盘操作与“查看全部”。
- 地图自动适配和“查看全部”包含道路折线，不仅适配点位包围盒，避免绕行路段被裁掉。日期范围使用非空的整趟标识，防止组件把它误判为空选项。
- 当前移动路由复用 Element Plus 业务页，移动壳也须加载组件样式、主题桥接及中文配置，并以 tripId 隔离详情上下文；独立 Vant 业务页面与安卓真机仍在后续阶段。

## 数据兼容与验证

现有 itinerary_items 已有 place_name、address、latitude、longitude；本次不增加数据库表或持久化派生路线。POI 标识仅随搜索结果返回，业务保存位置快照以避免供应商变更影响历史记录。

验证覆盖：高德响应解析、空字段数组、路线模式和距离单位、认证/参数/错误映射、缓存不移动坐标、草稿坐标保存和清空、乱序请求、排序后的相邻关系、地图实例清理；使用真实 Key 检查地点搜索、三种算路与浏览器地图渲染，记录实际结果。
