# Tripfolio 前端主题体系设计 v0.1

日期：2026-09-13
状态：已获用户批准方向（2026-09-13 会话），本文为实现依据。
设计依据：技术选型与架构建议 v0.4（桌面壳 Element Plus、移动壳 Vant 4、图表 ECharts 两端共用、平台能力经 `src/platform` 接口）。
适用范围：`apps/client` 的网页桌面壳、网页移动壳与 Capacitor 安卓应用。

## 1. 目标与原则

- 用户在“主题中心”点击即可切换整套界面风格；首批预置两套主题：**有机自然**（流动形状、自然色调、柔和曲线）与**玻璃态**（半透明白色玻璃、模糊背景、高光与细边形成的立体质感）。
- 新增主题只新增文件与一条注册表记录，不修改页面、组件与壳的代码。
- 两个壳共用同一套主题定义、状态与持久化，只有主题中心的视图按壳各自实现。
- 主题是本地偏好，不进入账号数据与同步协议；跨设备同步留待后续需求确认。

设计原则：

1. **页面只认项目语义令牌** `--tf-*`。页面与组件的样式禁止出现字面颜色、圆角、阴影、模糊值，也不直接引用 `--el-*`、`--van-*`。
2. **组件库靠桥接跟随令牌**。两份桥接文件把 `--tf-*` 映射为 `--el-*` 与 `--van-*`，只写一次，主题不碰。
3. **主题只做两件事**：给全部令牌赋值（`tokens.css`），以及对固定的“表面清单”做装饰（`decor.css`）。主题文件不得出现页面私有选择器。
4. **令牌集合是封闭契约**。必需令牌清单在代码中声明，测试保证每个主题定义的令牌集合与清单完全一致。
5. **全站配色禁止蓝紫色**（用户 2026-09-13 决定）。任何主题的颜色令牌、装饰层字面色与预览色，色相 190–310 且饱和度高于 0.1 的一律视为违规，由测试强制；中性灰、绿、青绿、暖色可用。

## 2. 分层

```
主题文件  src/themes/<id>/tokens.css   [data-theme="<id>"] { --tf-*: ... }
          src/themes/<id>/decor.css    背景装饰、模糊、高光等无法用变量表达的规则
          src/themes/<id>/index.css    @import 上面两份
              │  赋值
              ▼
语义令牌  --tf-*                        页面、壳、组件唯一允许引用的变量
              │  映射（只写一次）
              ▼
桥接      src/styles/bridge/element-plus.css   :root { --el-*: var(--tf-*) } 及少量组件级变量
          src/styles/bridge/vant.css           :root { --van-*: var(--tf-*) }
              │
              ▼
组件库    Element Plus（桌面壳）、Vant（移动壳）
              │
              ▼
页面      src/desktop/**、src/mobile/**   scoped CSS 只写 var(--tf-*)
```

跨主题不变的内容放 `src/styles/base.css`：重置、中文字体栈（`--tf-font-body`、`--tf-font-display` 默认取同一栈）、安全区内边距、`.tf-surface`/`.tf-backdrop` 等钩子类的基础规则、切换主题时抑制过渡的辅助类。原 `src/style.css` 并入该文件。

加载顺序：组件库样式 → 桥接（同为 `:root` 声明，后者覆盖前者）→ 主题（`[data-theme]` 选择器特异性更高，任何顺序都生效）。桥接随各自的壳按需引入，移动包不含 Element Plus 桥接。

## 3. 令牌契约

全部令牌以 `--tf-` 为前缀，按主题在 `[data-theme="<id>"]` 下赋值。清单在 `src/shared/theme/tokens.ts` 的 `REQUIRED_TOKENS` 声明，本表与之保持一致。

| 组 | 令牌 | 含义 |
| --- | --- | --- |
| 强调色 | `accent`、`accent-contrast`、`accent-soft` | 主色、主色上的文字色、主色淡底 |
| 语义色 | `success`、`warning`、`danger`、`info` 及各自 `-soft` | 状态色与淡底 |
| 表面 | `canvas`、`surface`、`surface-raised`、`surface-sunken`、`surface-inset` | 页面底、卡片与面板、弹层、输入与骨架填充、面板内列表条目底色 |
| 文字 | `text-1`、`text-2`、`text-3`、`text-disabled` | 主、次、辅助、禁用 |
| 线与遮罩 | `line`、`line-soft`、`overlay` | 边框、分隔线、模态遮罩 |
| 形状 | `radius-control`、`radius-card`、`radius-panel`、`radius-organic` | 控件、卡片、对话框、四角不对称的装饰圆角 |
| 表面效果 | `surface-blur`、`surface-border`、`surface-highlight` | 背景模糊半径、表面边框简写、内高光阴影 |
| 光影 | `shadow-1`、`shadow-2`、`shadow-3` | 三级阴影 |
| 背景装饰 | `backdrop` | 壳层固定背景的 `background` 简写 |
| 动效 | `ease`、`duration-fast`、`duration` | 缓动曲线、快慢两档时长 |
| 图表 | `chart-1` … `chart-6` | ECharts 系列色板（切片 4 接入时读取） |

值的书写规则：颜色令牌只允许 6 位十六进制 `#rrggbb` 或 `rgb(r g b / a)` 两种写法，便于测试解析并做对比度校验。对比度门槛：`text-1`、`text-2` 相对 `canvas` 与合成后的 `surface` 不低于 4.5:1；`text-3` 不低于 3:1。

2026-09-14 行程点补充：每日面板内的行程条目使用 `surface-inset`，不复用为菜单等浮层保留的 `surface-raised`。玻璃主题的内层白色填充 alpha 为 0.24，保留细分隔边线，不新增逐条模糊或阴影；磨砂与高光仍由外层每日面板承担。有机自然主题的内层保持原白底。减少透明度、强制颜色与不支持模糊时，玻璃内层令牌回退为不透明底色。完成／跳过通过标签、标题色与删除线表达，不降低整行文字或保存中的整块面板透明度。

2026-09-14 图标操作补充：回收站与主题导航、刷新、新建行程及分组添加采用统一线性 SVG 图标，颜色使用 `currentColor` 继承主题。导航保持真实链接，动作保持按钮；无可见文字时提供描述性 `aria-label` 与悬停／键盘提示，图标本身对辅助技术隐藏。点击区域桌面 40px、窄屏或触屏 44px；加载时保留可访问名称、禁用重复动作并显示忙碌状态。确认及复杂业务操作保留说明文字。

2026-09-15 操作统一补充：按用户选择，操作图标统一使用 Lucide 的 Vue 3 包 `@lucide/vue`，只按名称导入实际使用的组件，不再维护手绘路径。旅行主导航用 `House`，编辑用 `Pencil`，删除用 `Trash2`，主题用 `Palette`，地图视图用 `Globe`，新建用 `Plus`，记一笔用 `ReceiptText`，刷新用 `RotateCw`，加载用 `LoaderCircle`。SVG 保留统一 24px 绘制网格，以 20px 和 1.5 线宽显示；点击区域不缩小，减少动态时加载图标保留静态缺口与忙碌状态。编辑与删除的名称包含操作对象，删除仍保留原确认步骤；预算的就地编辑用铅笔提示且保留可访问名称。`IconAction` 区分导航外观与描边按钮外观，地图入口保留真实路由链接但显示为图标按钮。提示通过悬停或焦点触发，不截获按钮的 Enter／空格或链接的 Enter。同组操作使用 `tf-actions`，图标和文字按钮共享基础层的 `--tf-control-size`（桌面 40px，窄屏／触屏 44px）；长文字允许换行并增长高度，不缩小图标命中区域，不改变无关表单控件的尺寸。账单工具栏不再单列“记录退款”，通过“记一笔”表单选择退款类型。 同行筛选控件通过 `tf-filter-controls` 使用相同最小高度，未套该作用域的普通表单保持原尺寸。

## 4. 组件库桥接要点

Element Plus 会从主色派生 `light-3/5/7/8/9` 与 `dark-2` 档位。桥接用 `color-mix(in oklab, …)` 统一计算：淡档向 `--tf-canvas` 混合、深档向 `--tf-text-1` 混合，这样亮色与暗色主题都只需提供一个主色。文字、背景、填充、边框、圆角、阴影、遮罩、字体、过渡时长与曲线全部映射；组件级变量只覆盖卡片与对话框的圆角、卡片背景。

Vant 映射主色、四个语义色、三档文字色、三档背景、边框色、三档圆角、激活色。暗色主题时在 `<html>` 上加 `van-theme-dark`（与 `ConfigProvider theme="dark"` 等价），让未桥接的内部灰阶随之切换。

## 5. 表面清单与钩子类

主题 `decor.css` 只允许作用于以下选择器：

- 项目钩子类：`.tf-surface`（页面自建的面板容器）、`.tf-backdrop`（壳层固定背景）、`.tf-card`（需要主题装饰的卡片，通常与 `ElCard` 同用）。
- 组件库表面：`.el-card`、`.el-dialog`、`.el-drawer`、`.el-message-box`、`.van-cell-group--inset`、`.van-nav-bar`、`.van-popup`。

玻璃态的 `backdrop-filter` 只用于这份清单，并在 `prefers-reduced-transparency: reduce` 下回退为不透明 `surface-raised`。有机自然的不对称圆角只用于卡片与面板，控件保持规整；不用 `clip-path` 裁切内容容器，避免弹出层被裁。

## 6. 注册表与运行时

- `src/shared/theme/registry.ts`：`themeIds`、`ThemeDefinition { id, name, description, colorScheme, preview, load }`、`themes`、`DEFAULT_THEME = 'organic'`、`findTheme()`。`load` 是动态 `import()`，每套主题的 CSS 单独成 chunk，首屏只加载当前主题。
- `src/shared/theme/dom.ts`：纯函数 `applyThemeToDocument(document, theme)`，设置 `data-theme`、`color-scheme`、`van-theme-dark`、`<meta name="theme-color">`，并在切换瞬间加 `tf-theme-switching` 类抑制全局过渡一帧，避免颜色拖影。
- `src/shared/stores/theme.ts`：Pinia store，`current`、`ready`、`definition`、`restore()`、`apply(id)`。`restore` 在应用挂载前执行，读取持久化值，未知值回退默认主题。
- 持久化经平台层：`Platform.preferences: KeyValueStore { get/set/remove }`。网页实现为 `localStorage`，安卓实现为 `@capacitor/preferences`。键名 `tripfolio.theme`。
- 主题中心：路由 `/themes`（名 `themes`），按现有 `PagePair` 模式分别提供桌面与移动页面，都只从注册表渲染。桌面壳顶栏与移动壳列表各加一个入口。

## 7. 与后续切片的衔接

- 切片 4 的 ECharts：在 `apply` 后读取 `--tf-chart-*` 与文字、线条令牌的计算值生成主题对象并 `registerTheme`，主题切换时重新注册并刷新图表。
- 切片 5 的高德地图：如需按主题切换地图样式，在 `ThemeDefinition` 增加可选字段，不改页面。
- 新增主题步骤：新建 `src/themes/<id>/` 三个文件、在 `themeIds` 与 `themes` 各加一条、运行测试（令牌完整性与对比度自动校验）。
