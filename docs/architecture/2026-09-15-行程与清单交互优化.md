# 行程与清单交互优化

日期：2026-09-15，对应 T.12 与用户最新十项交互要求，覆盖前序尚未收尾的 Lucide 与尺寸统一。

## 行程表单与地点记账

- 对话框仍保留“新建行程／编辑行程”的名称；移除的是内容中的标题输入框。
- 顺序为类型／所属日期、搜索与地图选点、计划时间、记录该地点花费、展开详情。
- 选点将标题、地点、地址、GCJ-02 经纬度作为一个快照更新。摘要由选点组件展示一次，不再单列可编辑字段。新建缺少有效选点时在选点区域提示；旧无定位条目可正常编辑。
- 地点记账复用现有记账表单与幂等写入，自动填入当前地点和所属日期。每次打开取当前草稿值；用户仍确认分类和金额。记账独立保存，界面说明取消行程不会撤销已保存的账单。保存后同步旅行币种锁定状态。
- 历史预计费用保留但不自动转为支出，不新增行程点与账单的数据库关联。
- 每次打开默认收起备注和实际情况；收起保留输入。详情校验出错时展开，按钮暴露展开状态并可用 Enter／空格操作。

## 地图与算路

- 选点和路线共用的地图支持滚轮缩放；仅在地图区域处理滚轮默认行为，不全局阻止页面滚动。删除缩放按钮，保留查看全部。真实 Chromium 复核发现本机 SDK 的内建滚轮开关并未实际改变级别，因此由组件归一化鼠标／触控板的滚轮量并立即调用公开缩放 API，关闭 SDK 内建滚轮以免重复缩放；缩放限制在 2–20 级。
- 滚轮缩放以**指针位置**为锚点，不再以地图中心缩放：指针下的地理位置在缩放前后停留在同一像素，指针在中心时行为与原来一致。做法是先按缩放倍数算出「新中心在缩放前容器像素坐标中的位置」（容器中心 O、指针 P、倍数 S＝2^Δzoom 时中心沿 O→P 移动 (P−O)×(1−1/S)），再用容器像素转经纬度得到新中心并立即设置；容器尚无布局或 SDK 未提供像素转换时退回原来的中心缩放。
- 旅行详情页右下角固定悬浮一个「看地图／看行程」按钮，作为页签之外的快捷入口：当前不在地图页签时指向地图页签，已在地图页签时指回行程页签。它渲染为**真实链接**而不是脚本按钮，因此可中键／Ctrl 点击在新标签打开；移动壳复用同一页面，窄屏下同样存在，位置按 `env(safe-area-inset-bottom)` 避开手机手势条，尺寸与焦点样式沿用 `--tf-control-size` 与 `--tf-*` 令牌。
- 根因核对：原前端并发数 2 不等于每秒请求限制；任何 429／503 会连带跳过剩余队列。后端未细分高德 QPS 错误、凭证错误和配额错误，没有供应商请求节奏控制。
- 后端将临时 QPS 限流与繁忙响应标为可稍后重试，配额／凭证及无路线明确区分。按供应商 Key 限制实际请求发起节奏，命中缓存不占上游配额；排队请求支持取消。
- 前端使用有限退避，遵守可恢复错误与 Retry-After，避免对长时间限额或永久错误重复请求；单段失败仅影响自身。保留成功缓存、旧请求取消和部分结果的真实提示。
- 六点五段的首轮短时失败应自动恢复；持续失败仍显示示意线与不完整统计，不伪造完整结果。实际现场错误码尚需受控联调确认，不将代码推断写成已观测事实。

## 行李与控件

- 行李 UI 仅 `pending`（待准备）、`ready`（已准备）；历史 `packed` 等同已准备，显示／筛选／进度一致。取消勾选写 pending，勾选写 ready，无关编辑不改写旧 packed。
- 用有名称的原生复选框语义和圆形外观，保存中禁用并呈现忙碌状态；保存结束恢复原勾选控件的键盘焦点，若筛选使本项消失则移到下一项或状态筛选框，不抢走用户已移开的焦点。保留编辑、删除、物品库及仅显示非空分类的规则。
- 工具栏筛选选择器、单选分段和按钮共用 `--tf-control-size`：桌面 40px，窄屏／粗指针 44px。规则限制在工具栏，不影响一般表单。
- 行李与待办进度条提供可访问名称和已准备／已完成条目数，避免辅助技术只能读到无上下文的百分比。
- 图标使用维护中的官方 `@lucide/vue`，按需导入；20px、1.5 线宽，图标缩小不缩命中区。Tooltip 不截获 Enter／空格。
- 移除账单地图及独立退款按钮，退款仍从记账类型选择。
