## 交付与入口

- 旅行详情 → 行程 → 新建／编辑：搜索景点、餐厅、酒店等高德 POI，点击地图或输入 GCJ-02 坐标；名称、地址、经纬度随行程保存。
- 行程列表：相邻已定位地点自动显示驾车／步行／骑行的道路距离与预计用时；调整地点或顺序后按新邻接关系计算，复用仍有效的路段缓存。
- 旅行详情“地图”页签，或账单“支出统计”头部“地图视图 · 查看行程路线”：默认展示整趟点位，按日期和行程顺序编号、连线；支持单日筛选、三种方式、点位列表定位、缩放与查看全部。
- 未定位项目单独列出；跨日和跳过未定位项目明确说明。无可用路线时保留示意虚线，不计作道路里程；预计时长不含停留。

## 运行与后续边界

- 本地 `.env` / `.env.local` 已配置两套凭证；生产构建和 API / Caddy 运行时各自注入，步骤见 `infra/README.md`。原有开发 API 仍需重启才能加载新增 Go 路由，修改凭证后 Vite 也需重启。
- 单账号限流与全局日额度为单进程内存状态，重启会重置；多副本部署应采用共享限额。个人套餐的实际权限／配额以高德控制台为准。
- 境外、不支持的路段、超出供应商距离限制、网络或配额问题会降级提示；不会虚构道路或费用。尚不含实时导航、公交规划或自动优化停靠顺序。
- 移动路由暂复用现有桌面业务组件；独立 Vant 页面、安卓真机、相册／预订中的选点仍属后续 5.3 / 5.4 及安卓阶段。
- 测试库中的联调数据只供验证，重跑数据库集成测试会清空它；不要将测试库当业务库。
