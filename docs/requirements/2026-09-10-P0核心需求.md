# Tripfolio P0 核心需求清单 v0.3

日期：2026-09-10；v0.3 修订于 2026-09-12  
目标用户：面向大众的个人旅行用户。  
平台：安卓移动端、网页端。  
状态：本版功能范围按用户确定的两大模块整理；细化规则作为产品设计建议。  
v0.3 修订：按用户给出的旅行管理页面流程收敛范围。删除文字笔记、旅行概览、分类预算，以及行程项目与账目、待办、预订、照片之间的关联；账单分类改为用户可管理；物资清单改为按类别物品库逐项选取；相册记录拍摄时刻与地点；旅行详情固定为行程、账单、行李清单、相册四个页签；记账币种默认 CNY。

本版从《功能清单 v0.1》中收敛 P0 范围，以本文件作为本版需求讨论依据。核心目标是让用户完成一次旅行的规划、准备、途中记录和旅后归档。

## 1. 模块结构

| 一级模块 | 功能组成 |
| --- | --- |
| 旅行管理 | 旅行基础能力；每日行程、行李清单、待办、预算、记账、开支统计、预订与资料、相册 |
| 账户 | 账号与个人空间、跨端同步与离线、数据管理 |

旅行基础能力负责管理每一趟旅行，其余八个业务子模块均围绕选中的旅行展开。旅行详情页固定四个页签：行程、账单（预算、记账、统计）、行李清单、相册；待办与预订资料从详情页内的次级入口进入，具体位置在界面设计时确定。账户中的同步、离线和数据管理能力覆盖所有旅行及其关联内容。

## 2. 旅行管理

### TR-00 旅行基础能力

- 在首页新增旅行；创建、编辑旅行时填写旅行名称、开始日期、结束日期、目的地和备注。记账币种默认 CNY，可在创建或编辑时更改。
- 首页按待出发、旅行中、已结束三个状态分组展示旅行，状态按今天与起止日期自动判断；按名称、目的地和状态查找。
- 点击单条旅行进入详情，详情包含行程、账单、行李清单、相册四个页签。
- 归档、取消归档旅行；归档后的记录仍可查看、补充和修正。
- 删除旅行时确认操作，将整趟旅行及关联内容放入旅行回收站。
- 修改旅行日期时保留已有行程和记录，对超出新日期范围的安排提示调整。

**核心信息：** 名称、开始日期、结束日期、目的地、备注、旅行阶段、归档状态、记账币种、总预算。

**关键规则：** 旅行阶段与归档状态分别表达。每条行程、物品、待办、账目、预订、资料和照片都归属于具体旅行。

### TR-01 每日行程

- 行程页按旅行起止日期自动列出每一天，每天的标题为“月.日 周几”，例如 9.20 周日；提供今日行程入口。
- 在某一天下新增、编辑、删除行程项目，支持景点、交通、住宿、餐饮和其他类型。
- 调整同一天内的项目顺序，将项目移动到其他日期。
- 记录地点与地址：在高德地图上选点或搜索地点，也可手动填写地址；一键打开高德地图导航。
- 设置计划开始、结束时间或停留时长；允许时间留空，支持跨日交通和住宿。
- 将项目标记为未完成、已完成或已跳过，补充实际发生情况。

**核心信息：** 标题、类型、所属日期、顺序、计划时间、地点、地址、预计费用、备注、完成状态、实际记录。

**关键规则：** 原计划与实际记录分别保留。行程项目与账目、待办、预订、照片之间不建立关联，删除或跳过项目不影响其他记录。

### TR-02 行李清单

- 按证件、数码产品、服装、生活用品、食品饮料、药品及其他类别整理物品。
- 自定义新增、编辑、删除物品，设置数量和备注。
- 提供按类别组织的内置物品库（例如证件类下的身份证、护照、学生证、户口簿），可逐项选取加入本次旅行的清单；与已有物品同类别同名时跳过。
- 物品状态支持待准备、已备齐、已装包，并可改回前一状态。
- 筛选待准备或未装包物品，按条目展示准备和装包进度。

**核心信息：** 物品名称、分类、数量、备注、准备状态。

**关键规则：** 从物品库加入的物品状态初始为待准备，与其他旅行的清单互不影响；“已备齐”表示物品已经具备，“已装包”表示已放入本次旅行的行李。

### TR-03 待办

- 新增、编辑、删除旅行准备事项，例如订票、购买保险、办理证件。
- 设置截止日期、备注。
- 标记完成或恢复未完成，筛选全部、未完成、已完成和逾期事项。
- 展示待办完成进度，在待办列表突出未完成与逾期事项。

**核心信息：** 标题、截止日期、备注、完成状态。

**关键规则：** 截止日期可留空；只有设置了截止日期且逾期未完成的事项才标识为逾期。本版以应用内状态展示为主。

### TR-04 预算

- 设置、修改旅行总预算；账单页顶部的统计框显示总花费（净支出）、剩余预算和总预算，总预算可在统计框中直接编辑。
- 选择本次旅行的记账币种，默认 CNY，每趟旅行先使用一种币种。
- 查看预算、净支出、剩余预算和超支金额。
- 未设置预算时也可以正常记账和查看支出统计。

**核心信息：** 记账币种、总预算。

**关键规则：** 预计费用与实际支出分别统计；剩余预算 = 总预算 − 净支出。存在账目期间旅行币种锁定，修改币种不会重标历史金额；删除全部账目后可再次更改币种。

### TR-05 记账

- 账单页点击记账，选择账单分类、输入金额即可保存；日期默认当天，旅行默认当前旅行。
- 账单分类按账号管理，跨旅行共用。系统预设交通、住宿、美食、景点、购物、其他；用户可在分类管理中新增、改名、排序和删除分类。
- 可补充备注和票据图片。
- 记录退款，可关联原支出；退款冲减对应分类的实际支出。
- 按日期、分类和记录类型查看明细。
- 支持记录出发前的预付款和旅行结束后的补记或退款。

**核心信息：** 支出或退款类型、金额、分类、实际发生日期、备注、原支出（退款时可选）、票据。

**关键规则：** 金额以正数输入，由支出或退款类型决定统计方向。有账目引用的分类不能删除，只能改名或排序。保存预订、预计费用或上传票据不会自动新增一笔支出。

### TR-06 开支统计

- 查看支出总额、退款总额、净支出、剩余预算和超支情况。
- 按实际发生日期查看每日支出，按分类查看汇总金额与占比。
- 查看分类占比，并从统计项进入对应明细。
- 支持日期和分类筛选，账目增删改后更新统计。
- 默认统计本次旅行的全部关联账目，包含出发前付款和结束后的退款。

**关键规则：** 净支出 = 支出总额 − 退款总额。分类占比按分类净支出计算；净支出不大于零或存在负值分类时，展示金额明细，避免产生无意义的占比图。

### TR-07 预订与资料

- 手动新增、编辑、删除交通、住宿、景点预约和其他预订信息。
- 保存订单备注、车次或航班、出发到达时间、入住退房时间、地址、联系电话等适用信息。
- 上传、查看、下载图片和 PDF 附件，编辑资料名称和备注；资料可作为预订的附件，也可独立保存。
- 将选定的重要资料保存到安卓本地，供离线查看。

**核心信息：** 类型、名称、预订编号或备注、相关时间、地点、联系方式、附件。

**关键规则：** 字段按预订类型提供，非必要信息可留空；预订与付款分别记录；删除预订时其资料保留为独立资料；资料默认仅本人可见。

### TR-08 相册

- 上传照片，编辑照片的拍摄时刻、地点和备注；移动端提供获取当前位置的按钮，通过高德定位与逆地理编码填入地点名称和地址。
- 按天展示相册，天由拍摄时刻的日期决定，未填写时刻时按添加当天归档。
- 安卓支持从相机或相册添加照片；网页支持文件上传和查看。
- 显示照片上传中、已完成或失败状态，失败后可重试。
- 支持旅行结束后补充整理。

**核心信息：** 所属旅行、拍摄时刻、归属日期、地点（名称、地址、可选坐标）、备注、文件状态。

**关键规则：** 照片自带的拍摄时间和位置只作为建议，是否采用由用户决定；上传失败不丢失已填写的说明。

## 3. 账户

### AC-01 账号与个人空间

- 注册、登录、退出登录和找回账号。
- 编辑头像、昵称等基础个人资料。
- 使用同一账号在安卓与网页访问自己的旅行数据。
- 查看账号基本信息，进入同步、离线、导出、回收站和注销入口。
- 登录失效时提示重新登录，妥善保留尚未同步的本地修改。

**关键规则：** 每个账号只能访问自己的私有数据；退出或切换账号后，前一账号的本地资料不能被其他账号读取。登录方式在后续账号设计中确定。

### AC-02 跨端同步与离线

- 同步旅行基础信息、每日行程、行李清单、待办、预算、账单分类、账目、预订、资料、照片和附件。
- 显示最近同步时间、待同步、同步中、已同步、同步失败状态；支持失败重试。
- 在安卓选择需要离线使用的旅行，以及需要下载的照片和附件；显示下载进度和是否准备完成。
- 离线查看已下载的旅行信息、统计、照片和资料。
- 离线新增或编辑账目，更新物品与待办的完成状态；联网后同步到账号。
- 在本地已保存账目发生变化时更新本地统计，并标明尚未同步的状态。
- 两端修改同一记录产生冲突时保留相关版本，提示用户选择保留内容。
- 重试和重新连接不会重复创建同一笔账目。

**本版平台边界：**

| 能力 | 安卓端 | 网页端 |
| --- | --- | --- |
| 在线访问与编辑全部核心模块 | 支持 | 支持 |
| 查看已下载的旅行、照片与附件 | 离线支持 | 本版以在线使用为主 |
| 记账、清单和待办状态更新 | 离线支持 | 本版以在线使用为主 |
| 创建旅行、编排行程、修改预算、预订与账单分类 | 本版在线操作 | 在线操作 |
| 新照片与附件上传 | 联网上传，可重试 | 联网上传，可重试 |
| 地图导航 | 调用外部地图，离线可用性取决于地图应用 | 调用外部地图服务 |

**关键规则：** 离线能力依赖已保存的旅行数据和已下载文件；下载或同步失败不能显示为完成。删除与编辑冲突时保留待处理内容，避免恢复连接后静默丢失修改。

### AC-03 数据管理

- 导出全部或选定旅行的数据包，包含行程、清单、待办、预算、账目、预订、资料、照片和附件。
- 单独导出开支 CSV，包含支出与退款类型、日期、分类、金额和备注。
- 提供旅行回收站，查看已删除旅行、剩余保留时间，恢复整趟旅行及其关联内容。
- 回收站建议保留 30 天；用户主动永久删除前明确确认范围和不可恢复的结果。
- 查看安卓离线资料占用空间，清理选定旅行的已同步本地副本。
- 支持账号注销，说明将删除的数据范围与处理进度，并进行身份验证与确认。

**关键规则：** 清理离线缓存不删除云端数据，不清除未同步记录；旅行回收站与本地缓存管理分别操作。本版提供数据导出和旅行回收站恢复，外部数据导入另行安排。

## 4. 共同规则与版本范围

1. 两端基础功能互通，安卓侧重途中操作和离线，网页侧重规划与整理。
2. 本版围绕个人管理自己的旅行，所有旅行内容默认私密。
3. 预算、计划费用、实际支出分别保留；实际统计统一按支出减退款计算。
4. 旅行日期调整、行程变更和归档均保留历史账目与记录；整趟旅行删除统一进入回收站。
5. 图片和附件可以被多处引用，解除单个引用不会导致其他位置的内容失效。
6. 失败的上传、下载和同步可见、可重试，用户已经保存的输入应被保留。
7. 本版物品库为内置数据；提醒以应用内截止状态和逾期标识为主。
8. 后续扩展沿用 v0.1 的 P1/P2 清单，包括系统提醒、多币种与跨时区增强、地图路线规划、智能识别、分享、多人协作和数据导入；v0.3 移出 P0 的文字笔记、旅行概览、分类预算，以及行程项目与其他记录的关联也列入后续扩展。
9. 地图、定位、选点、逆地理编码与导航统一使用高德开放平台；所有地点坐标以 GCJ-02 坐标系保存。高德对境外地点覆盖有限，境外旅行允许只填写文字地址。

## 5. 本版完成标准

- 用户能在网页创建旅行，安排多天行程、准备行李清单与待办，保存预算和预订资料。
- 安卓登录后显示相同内容，并可下载本次旅行和重要资料供离线查看。
- 旅途中能够完成常用记录；断网时完成指定离线操作，联网后网页能够看到同步结果。
- 行前预付款、旅中支出和旅后退款都归入对应旅行，统计结果与账目一致。
- 旅行结束后可以整理相册、补记账目、归档并再次查看。
- 用户能够导出自己的旅行数据，恢复回收站内的旅行，清理本地缓存而不误删云端数据。
- 不同账号的数据互相隔离；同步冲突、失败上传与未下载资料均有明确状态。
